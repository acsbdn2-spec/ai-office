# Voice samples

Every file reads the same text:

> নমস্কার! আজকে সহজ ভাষায় দেখব, GSTR-1 আর GSTR-3B-র তফাৎ। ধরুন ₹1,800 GST দিয়েছেন, তাহলে সেটা ITC হিসেবে পাবেন। আর 3B জমা দেওয়ার শেষ তারিখ, পরের মাসের 20 তারিখ। ভিডিওটা ভালো লাগলে Like আর Share করুন!

With the pronunciation rules the voice reads:

> নমস্কার! আজকে সহজ ভাষায় দেখব, জি এস টি আর ওয়ান আর জি এস টি আর থ্রি বির তফাৎ। ধরুন এক হাজার আটশো টাকা জি এস টি দিয়েছেন, তাহলে সেটা আই টি সি হিসেবে পাবেন। আর থ্রি বি জমা দেওয়ার শেষ তারিখ, পরের মাসের কুড়ি তারিখ। ভিডিওটা ভালো লাগলে লাইক আর শেয়ার করুন!
